# API Attacks (RESTful)

Módulo sobre APIs RESTful tudo em **`/swagger`**, percorrendo pelo OWASP de API:

**OWASP API Security Top 10:**

- **Broken Object Level Authorization (IDOR de API)**
    
    Quando o sistema falha na autorizacao, e usuarios tem permissao de request para ver data ou performar operacoes em algo que nao poderia.
